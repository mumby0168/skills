# Fork skills

Local skills layered onto the upstream collection.

## User-invoked

- **[gripe](./gripe/SKILL.md)**: Turn one code complaint into an agreed fix and a tested guardrail.

- **[upstream-update](./upstream-update/SKILL.md)**: Merge upstream into a review branch while preserving the changes listed in [FORK.md](../../FORK.md).

## PR review

Guided PR review: an HTML overview first, then terminal sparring stop by stop, with research in subagents.

### User-invoked

- **[guided-review](./pr-review/guided-review/SKILL.md)**: Walk me through a PR: an HTML overview first, then terminal sparring stop by stop.

### Model-invoked

- **[pr-intent](./pr-review/pr-intent/SKILL.md)**: Linked tickets, their project and siblings, and git history of the touched area.
- **[pr-map](./pr-review/pr-map/SKILL.md)**: Changed-file trees chunked by concern and a numbered stop plan.
- **[pr-lenses](./pr-review/pr-lenses/SKILL.md)**: Light flags on tests, ticket fit, codebase patterns and blast radius.
- **[review-log](./pr-review/review-log/SKILL.md)**: The HTML overview page and growing review log.
- **[review-comments](./pr-review/review-comments/SKILL.md)**: Severity-labelled comments written for the author.
- **[render-contract](./pr-review/render-contract/SKILL.md)**: API, event and DB contracts, or changes to them, as annotated JSONC or a schema tree.
